### 4.2 主流程（請確認這三條就夠這次驗收）

**流程 A — 訪客逛官網**

1. 打開 https://waitengchong.github.io/Bold-website/
2. 看首頁 Hero、活動、Club News、相簿
3. 點 Facility 看場館
4. 點 Booking / Membership / Mission / Staff → Coming Soon
5. 需要時點 Log in 或 Sign up

**流程 B — 會員註冊／登入（本機示範）**

1. Sign up：選區碼、輸入手機、密碼（至少 8 字）、確認密碼
2. 送出後進入已登入狀態（同一瀏覽器）
3. Log in：同一組手機＋密碼可再登入
4. 登出後須重新登入

**流程 C — 管理員改首頁內容（只影響此瀏覽器）**

1. 以管理員身分登入（帳密由內部提供，不寫在本文件）
2. 進入 Admin → Content
3. 改 Hero 照片／標題、活動卡片、或新聞
4. 可 Preview Homepage，再 Save
5. 同一瀏覽器打開首頁應看到新內容；**換手機或無痕視窗仍是預設內容**

- [ ] 以上三條流程正確，這次驗收以這三條為準。

## 7. 規則與限制（講得出、測得到）

- [ ] 註冊密碼至少 8 個字元；兩次密碼須相同。
- [ ] 同一瀏覽器已註冊的手機號不可再註冊。

- [ ] CMS 儲存後，**僅此瀏覽器**的首頁跟著變；不能當成「改一次全香港都看到」。
